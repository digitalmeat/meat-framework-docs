WordPress development,
the right way.

MEAT Framework is an opinionated WordPress development stack built on top of Themosis — bringing Laravel-style architecture, Blade templates, Eloquent ORM, and Artisan CLI to your WordPress projects.

Get Started Read the Docs 
composer create-project digitalmeat/meat-framework my-project
⚡

Laravel-style Routing

Define WordPress routes with a clean, expressive API. Use conditional tags or custom URIs with full middleware support.

🧩

Blade Templates

Write your views with Blade — the elegant, powerful templating engine from Laravel. Escape the PHP spaghetti for good.

🗄️

Eloquent ORM

Interact with your database using Laravel's beautiful ActiveRecord implementation, fully integrated with WordPress.

🛠️

Artisan CLI

Generate boilerplate, run migrations, manage your app — all from the command line with familiar Artisan commands.

🐳

Docker Ready

Production-grade Docker setup included. Spin up a local environment in minutes with docker-compose up.

🔒

Actively Maintained

Themosis was abandoned — MEAT Framework picks up where they left off. Security patches, PHP 8.x compatibility, ongoing improvements.

Quick start

01

Install via Composer

composer create-project digitalmeat/meat-framework my-project
02

Configure your environment

cp .env.sample .env
# Edit .env with your DB credentials
03

Install a theme & WordPress

php artisan theme:install my-theme
php artisan migrate
