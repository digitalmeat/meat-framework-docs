Application structure

A MEAT Framework project follows a standard directory layout. The web server document root is the htdocs/ subdirectory — never the project root.

Root directory

my-project/
├── app/                    # PHP application code
│   ├── Hooks/              # Hookable classes (WordPress lifecycle entry points)
│   ├── Http/
│   │   ├── Controllers/    # Route controllers
│   │   ├── Middleware/     # HTTP middleware
│   │   └── Kernel.php
│   ├── Models/             # Eloquent models
│   ├── Providers/          # Service providers
│   └── Services/           # Business logic / services
├── bootstrap/              # Application bootstrapper
├── config/                 # Configuration files
├── database/
│   └── migrations/         # Database migrations
├── htdocs/                 # ← WEB SERVER DOCUMENT ROOT
│   ├── cms/                # WordPress core installation
│   └── content/
│       └── themes/         # Your custom theme(s)
├── resources/
│   └── views/              # Global Blade/Twig views
├── routes/
│   └── web.php             # Application routes
├── .env                    # Environment variables (not committed)
├── .env.sample             # Template for .env
└── composer.json

config/ directory

  • app.php — application settings, hooks registration, WordPress conditions
  • database.php — DB connections
  • wordpress.php — WordPress constants (replaces wp-config.php)
  • assets.php — asset paths configuration
  • view.php — view directories

Theme directory

htdocs/content/themes/my-theme/
├── config/         # Theme-specific config (assets, templates, etc.)
├── dist/           # Compiled assets (output from your build tool)
├── resources/
│   └── js/         # JavaScript source
│   └── scss/       # SCSS source
└── views/          # Blade/Twig template files

Routes

All web routes live in routes/web.php. The web middleware group is automatically applied. See the Routing guide for the full API.
