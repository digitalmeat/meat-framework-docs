Introduction

The PostType facade provides a fluent API to register and manage WordPress custom post types. Register them inside a Hookable class so they load before WordPress is ready.

Basic registration

<?php

namespace App\Hooks;

use Meat\Hook\Hookable;
use Meat\Support\Facades\PostType;

class Books extends Hookable
{
    public function register(): void
    {
        PostType::make('books', 'Books', 'Book')->set();
    }
}

Register in config/app.php:

'hooks' => [
    App\Hooks\Books::class,
],
Important: The custom post type will only be registered once you call set().

make() signature

PostType::make(string $slug, string $pluralName, string $singularName)

Labels

make() pre-fills the standard labels from the plural and singular names. Override specific labels with setLabels(): 

PostType::make('books', 'Books', 'Book')
    ->setLabels([
        'add_new_item'  => __('Add a book', 'textdomain'),
        'edit_item'     => __('Edit book', 'textdomain'),
        'not_found'     => __('No books found', 'textdomain'),
    ])
    ->set();

Customizing arguments

Pass any argument from register_post_type() to setArguments(): 

PostType::make('books', 'Books', 'Book')
    ->setArguments([
        'public'        => true,
        'has_archive'   => true,
        'menu_position' => 20,
        'menu_icon'     => 'dashicons-book-alt',
        'supports'      => ['title', 'editor', 'thumbnail', 'custom-fields'],
        'rewrite'       => ['slug' => 'books'],
        'show_in_rest'  => true, // enables Gutenberg + REST API
    ])
    ->setTitlePlaceholder('Enter book title...')
    ->set();

Getters

$books = PostType::make('books', 'Books', 'Book')->set();

// Name / slug
$slug = $books->getName();   // 'books'
$slug = $books->getSlug();   // 'books'

// All arguments
$args = $books->getArguments();

// Single argument
$pos = $books->getArgument('menu_position');

// All labels
$labels = $books->getLabels();

// Single label
$label = $books->getLabel('add_new_item');

// The WP_Post_Type instance
$wpType = $books->getInstance();

Service container

Each registered post type is bound in the illuminate/container as meat.posttype.{slug}: 

// Via helper
$books = app('meat.posttype.books');

// Via facade
use Illuminate\Support\Facades\App;
$books = App::make('meat.posttype.books');

Custom statuses

Add custom publish statuses to your post type with status(). When custom statuses are added, all defaults except draft and trash are removed. The first defined status acts as the "Publish" action.

Single status

PostType::make('books', 'Books', 'Book')
    ->status('rent', [
        'publish_text' => __('List for rent', 'textdomain')
    ])
    ->set();

Multiple statuses

PostType::make('books', 'Books', 'Book')
    ->status([
        'rent' => [
            'publish_text' => 'Save and list for rent'
        ],
        'rented' => [
            'publish_text' => 'Mark as rented'
        ],
        'sell' => [
            'publish_text' => 'List for sale'
        ],
        'sold' => [
            'publish_text' => 'Mark as sold'
        ],
    ])
    ->set();

Status properties follow the same API as register_post_status(). The additional publish_text property overrides the "Publish" button label for that specific status.
