Introduction

MEAT Framework is an opinionated WordPress development stack maintained by Digital MEAT. It is a direct continuation of the MEAT Framework 3.1 framework, which was abandoned by its original authors.

The goal is to provide a common, Laravel-style coding structure and better tools for bespoke WordPress application development — without abandoning the WordPress ecosystem your clients and team already know.

What is MEAT Framework?

MEAT Framework wraps WordPress with a full Laravel-inspired application layer:

  • Routing — clean URI and WordPress conditional-tag routes via illuminate/routing
  • Blade & Twig — modern templating engines, no more raw PHP in views
  • Eloquent ORM — ActiveRecord models for your database tables
  • Artisan CLI — code generation, migrations, and custom commands
  • Service container — dependency injection throughout the app
  • Middleware — HTTP request/response pipeline with full Laravel compatibility
  • Docker — production-ready container setup included out of the box

Relationship to MEAT Framework

MEAT Framework is a fork of Themosis 3.1. MEAT Framework was created by Julien Lambé and was the best WordPress development framework available. When active development stopped, Digital MEAT took over maintenance to keep it alive for production projects.
