Views

MEAT Framework uses illuminate/view with two template engines: Blade and Twig.

Views are loaded from your theme's views/ directory and resources/views/ at project root. Add directories in config/view.php or config/theme.php.

Creating & rendering views

// Routes
Route::any('front', function($post, $query) {
    return view('pages.home', ['name' => 'World']);
});

// Controller
public function index() { return view('pages.home', ['posts' => get_posts()]); }

// Render to string (e.g. emails)
$html = view('emails.receipt', ['order' => $order])->render();
wp_mail($to, 'Receipt', $html);
No need to call render() when returning from a route or controller — the framework handles it.

Organize with dot notation

return view('pages.about');         // views/pages/about.blade.php
return view('emails.confirm');      // views/emails/confirm.blade.php
return view('partials.card');       // views/partials/card.blade.php

Passing data

return view('page', ['title' => 'About', 'team' => $team]);
return view('page')->with('title', 'About')->with('team', $team);
return view('page')->with(['title' => 'About', 'team' => $team]);

Sharing data across all views

use Illuminate\Support\Facades\View;
View::share('siteName', get_bloginfo('name'));
View::share(['siteName' => get_bloginfo('name'), 'siteUrl' => home_url()]);

View composers

// Closure
View::composer('pages.home', function($view) {
    $view->with('recent', get_posts(['numberposts' => 5]));
});

// Multiple views
View::composer(['pages.home', 'partials.sidebar'], function($view) {
    $view->with('categories', get_categories());
});

// Class method
View::composer('pages.home', 'App\View\Composers\HomeComposer@compose');
namespace App\View\Composers;
use Illuminate\View\View;

class HomeComposer {
    public function compose(View $view): void {
        $view->with('featured', get_posts(['meta_key' => 'featured', 'meta_value' => '1']));
    }
}
