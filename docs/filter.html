Filter

The Filter facade wraps the WordPress filter API. Mirrors Action with the same API — the key difference is that filter callbacks must return a value.

Register a filter

use Meat\Support\Facades\Filter;

Filter::add('the_title', 'App\Hooks\Filters\TitleFilter@process');
// Omit method when it matches filter name:
Filter::add('the_title', 'App\Hooks\Filters\TitleFilter');

Priority & arguments

Filter::add('get_attached_file', 'App\Hooks\MyFilter@filter', 5, 2);

Functions, closures & instances

Filter::add('the_content', 'my_filter_fn');
Filter::add('the_content', function(string $c): string { return $c . '<p>Footer</p>'; });
Filter::add('the_title', [$this, 'filterTitle']);
Filter::add('the_title', [new MyFilter(), 'process']);

Constructor injection

Constructor dependencies are auto-resolved via illuminate/container when using Namespace\Class@method:

namespace App\Hooks\Modules;
use App\Services\Editor\Tools; use Illuminate\Http\Request;

class ContentFilter {
    public function __construct(private Request $r, private Tools $t) {}
    public function the_content(string $content): string {
        return $this->t->process($content);
    }
}
Filter::add('the_content', 'App\Hooks\Modules\ContentFilter');

Run / check / remove

$result = Filter::run('my_filter', $value);
if (Filter::exists('my_filter')) { /* registered */ }
$f = Filter::add('the_title', 'SomeClass@method');
$f->remove('the_title');            // default priority 10
$f = Filter::add('the_title', 'SomeClass@method', 5);
$f->remove('the_title', 5);         // custom priority
