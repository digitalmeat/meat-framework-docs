Contribution guide

MEAT Framework is open-source (GPL-2+). All contributions are welcome.

Ways to contribute

  • Report a bug — open an issue on GitHub with steps to reproduce
  • Suggest a feature — open a discussion or issue describing the use case
  • Send a pull request — fork, make changes on a feature branch, open a PR against main
  • Improve docs — docs site repo: github.com/digitalmeat/meat-framework-docs

Pull request process

  1. Fork github.com/digitalmeat/themosis3.0
  2. git checkout -b feature/my-improvement
  3. Make changes with clear commit messages
  4. composer test — all tests must pass
  5. pnpm lint — no lint errors
  6. Push and open the PR against main

Local setup

git clone https://github.com/digitalmeat/themosis3.0.git my-project
cd my-project
composer install
cp .env.sample .env
# fill DATABASE_* in .env
php artisan key:generate
php artisan salts:generate
php artisan migrate
corepack enable pnpm
pnpm install
pnpm build

Code style

PHP follows PSR-12. JavaScript/TypeScript follows the project ESLint config. Pre-commit hooks run lint-staged automatically.
