Middleware

Middleware filter HTTP requests before reaching routes, using illuminate/routing. Dependencies are injected via illuminate/container.

Create

php artisan make:middleware CheckCapability
namespace App\Http\Middleware;
use Closure; use Illuminate\Http\Request;

class CheckCapability {
    public function handle(Request $request, Closure $next, string $cap = 'read'): mixed {
        if (!current_user_can($cap)) return redirect('/');
        return $next($request);
    }
}

Register & assign

Register in $routeMiddleware in app/Http/Kernel.php:

protected $routeMiddleware = [
    'wp.bindings' => \Meat\Route\Middleware\WordPressBindings::class,
    'wp.can'      => \Meat\Route\Middleware\WordPressAuthorize::class,
    'wp.cap'      => \App\Http\Middleware\CheckCapability::class,
    'bindings'    => \Illuminate\Routing\Middleware\SubstituteBindings::class,
];
Route::get('dashboard', [DashboardController::class, 'index'])->middleware('wp.can');
Route::get('/', fn() => view('home'))->middleware(['wp.can', 'log']);

Middleware groups

MEAT Framework ships with web, api, and admin groups. web is auto-applied to routes/web.php.

Route::prefix('api')->middleware('api')->group(function() {
    Route::get('posts', [PostApiController::class, 'index']);
});

Parameters

Route::post('post/{id}', fn() => null)->middleware('wp.cap:edit_posts');
// Received as: handle(Request $r, Closure $next, string $cap): mixed

Terminable middleware

class RequestLogger {
    public function handle(Request $r, Closure $next): mixed { return $next($r); }
    public function terminate(Request $r, $response): void {
        error_log($r->method().' '.$r->path()); // runs after response is sent
    }
}

See Laravel middleware docs for the full API.
