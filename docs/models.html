Introduction

MEAT Framework ships with full support for Laravel Eloquent ORM via the illuminate/database package. Eloquent is an ActiveRecord implementation: each database table has a corresponding Model class.

Available database tools:

  • Query Builder — fluent SQL builder
  • Eloquent ORM — ActiveRecord models
  • Migrations — version-controlled schema changes
  • Collections — fluent array-like result sets

Database connection is configured in config/database.php. MySQL is the default.

Creating a model

php artisan make:model Book

# With migration
php artisan make:model Book --migration
php artisan make:model Book -m

Models live in app/Models/ and extend Illuminate\Database\Eloquent\Model:

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Book extends Model
{
    // Eloquent assumes table name = "books" (snake_case plural of class name)
    // Eloquent assumes primary key = "id"
    // Eloquent manages created_at / updated_at automatically
}

Common model configuration:

class Book extends Model
{
    // Override table name
    protected $table = 'library_books';

    // Disable timestamps
    public $timestamps = false;

    // Mass-assignable fields
    protected $fillable = ['title', 'author', 'isbn'];

    // Fields hidden from arrays/JSON
    protected $hidden = ['internal_notes'];
}

Working with WordPress tables

WordPress uses its own column naming conventions. You need to tell Eloquent about them. The table prefix (e.g. wp_) is handled automatically — never include it in $table.

The wp_posts table

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    // WordPress table: wp_posts
    // Eloquent maps "posts" -> "wp_posts" via configured prefix
    protected $table = 'posts'; // do NOT include prefix

    // WordPress primary key is "ID", not "id"
    protected $primaryKey = 'ID';

    // WordPress uses different timestamp column names
    const CREATED_AT = 'post_date';
    const UPDATED_AT = 'post_modified';
}

Usage examples:

// Get all published posts
$posts = Post::where('post_status', 'publish')
             ->where('post_type', 'post')
             ->orderBy('post_date', 'desc')
             ->get();

// Find by ID
$post = Post::find(42);

// Get post meta via a relationship
class Post extends Model
{
    public function meta()
    {
        return $this->hasMany(PostMeta::class, 'post_id', 'ID');
    }
}

Migrations

# Create a migration
php artisan make:migration create_books_table

# Run pending migrations
php artisan migrate

# Rollback last batch
php artisan migrate:rollback

# Rebuild from scratch
php artisan migrate:fresh

Example migration:

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('books', function (Blueprint $table) {
            $table->id();
            $table->string('title');
            $table->string('author');
            $table->string('isbn', 20)->unique();
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('books');
    }
};
