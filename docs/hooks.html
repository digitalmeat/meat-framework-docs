Introduction

MEAT Framework lets you extend WordPress from the application root using Hookable classes — PHP classes that run your code in the context of the WordPress lifecycle, before mu-plugins load. This replaces the need for mu-plugin files to bootstrap application features.

When you are inside a theme or plugin (where all WordPress APIs are already loaded), use the Action or Filter facades directly instead. Hookable classes are the application-level entry point only.

Default hook classes

The framework ships with built-in hookable classes in app/Hooks/. The Application class is the primary one — it loads core framework assets and features. Review each file; they are self-documented.

Creating a hook class

php artisan make:hook MyHook

This generates app/Hooks/MyHook.php:

<?php

namespace App\Hooks;

use Meat\Hook\Hookable;

class MyHook extends Hookable
{
 /**
 * Extend WordPress.
 */
 public function register(): void
 {
 // Your code runs here — all WordPress APIs available
 add_image_size('hero', 1440, 600, true);
 }
}

Registering hook classes

Hookable classes are not auto-discovered. Add them to config/app.php:

// config/app.php
'hooks' => [
 App\Hooks\Application::class,
 App\Hooks\MyHook::class,
],

Running on a specific WordPress action

By default, a hookable class runs immediately (before mu-plugins). Use the $hook property to defer execution to any WordPress action: 

<?php

namespace App\Hooks;

use Meat\Hook\Hookable;

class RegisterMenus extends Hookable
{
 public string $hook = 'after_setup_theme';

 public function register(): void
 {
 register_nav_menus([
 'primary' => 'Primary navigation',
 'footer' => 'Footer navigation',
 ]);
 }
}

Filter hooks

Hookable classes can also act as filters. The register() method receives the filter parameters and must return a value: 

<?php

namespace App\Hooks;

use Meat\Hook\Hookable;

class CustomExcerptLength extends Hookable
{
 public string $hook = 'excerpt_length';

 public function register(int $length): int
 {
 return 20;
 }
}
<?php

namespace App\Hooks;

use Meat\Hook\Hookable;

class CleanTitleFilter extends Hookable
{
 public string $hook = 'the_title';

 public function register(string $title): string
 {
 return ucwords(strtolower($title));
 }
}

Priority

Control the execution order with the $priority property (default: 10):

class LateHook extends Hookable
{
 public string $hook = 'init';
 public int $priority = 99;

 public function register(): void
 {
 // Runs late in the "init" action
 }
}
Tip: For one-off actions and filters inside controllers, views, or services, use the Action and Filter facades — they are simpler and don't require a class.
