Drop-ins

WordPress drop-ins are PHP files placed in WP_CONTENT_DIR (htdocs/content/ in MEAT Framework) that override specific core behaviors.

Available drop-ins

  • db.php — custom database class
  • db-error.php — custom database error page
  • advanced-cache.php — page caching (required by cache plugins)
  • object-cache.php — persistent object cache (Redis, Memcached)
  • maintenance.php — custom maintenance page
  • fatal-error-handler.php — custom fatal error handler (WP 5.2+)

Placement

htdocs/content/
├── object-cache.php    # Redis/Memcached drop-in
├── advanced-cache.php  # Page cache drop-in
└── themes/
    └── my-theme/

Example: Redis object cache

Configure in config/wordpress.php:

define('WP_REDIS_HOST', env('REDIS_HOST', '127.0.0.1'));
define('WP_REDIS_PORT', env('REDIS_PORT', 6379));
define('WP_REDIS_DATABASE', env('REDIS_DB', 0));
# .env
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_DB=0
Drop-ins load before plugins and the application bootstrap — they cannot use the service container or facades.
