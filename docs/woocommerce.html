WooCommerce

MEAT Framework integrates with WooCommerce by extending the routing conditional tags and allowing WooCommerce templates to use Blade/Twig views.

WooCommerce routes

Register WooCommerce conditional tags in config/app.php:

// config/app.php
'conditions' => [
    // ... default conditions ...
    'is_shop'            => 'shop',
    'is_product'         => 'product',
    'is_product_category' => 'product-category',
    'is_product_tag'     => 'product-tag',
    'is_cart'            => 'cart',
    'is_checkout'        => 'checkout',
    'is_account_page'    => 'account',
    'is_wc_endpoint_url' => 'wc-endpoint',
],

Then define routes:

// routes/web.php

// Shop archive — register BEFORE generic 'page' route
Route::any('shop', function($post, $query) {
    return view('woo.shop', ['products' => wc_get_products(['limit' => 12])]);
});

// Single product
Route::any('product', function($post, $query) {
    return view('woo.product', ['product' => wc_get_product($post->ID)]);
});

// Cart
Route::any('cart', function($post, $query) {
    return view('woo.cart');
});

// Generic page route LAST
Route::any('page', function($post, $query) {
    return view('page', compact('post'));
});

The shop route references a WordPress page. Define it before the generic page route or the page route will match first.

WooCommerce template override

Override WooCommerce PHP templates by placing them in htdocs/content/themes/my-theme/woocommerce/. This is the standard WooCommerce override mechanism — no framework-specific step needed.

WooCommerce hooks

// In a Hookable class
class WooHooks extends Hookable
{
    public string $hook = 'woocommerce_init';

    public function register(): void
    {
        // Remove default WC actions
        remove_action('woocommerce_before_main_content', 'woocommerce_output_content_wrapper');
        remove_action('woocommerce_after_main_content',  'woocommerce_output_content_wrapper_end');

        // Add custom actions
        add_action('woocommerce_before_shop_loop', function() {
            echo view('woo.partials.shop-header')->render();
        });
    }
}
