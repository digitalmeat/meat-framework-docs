Action

The Action facade wraps the WordPress action/hook API. Use add() to register actions.

Register an action

use Meat\Support\Facades\Action;

Action::add('init', 'App\Hooks\Modules\Shop@init');
// Omit method when it matches the action name:
Action::add('init', 'App\Hooks\Modules\Shop');
Note: Always use the full class name with namespace. Methods must be public.

Priority & argument count

// 3rd arg = priority (default 10), 4th = accepted arguments (default 3)
Action::add('init', 'App\Hooks\MyClass@method', 5, 2);

Functions, closures & instances

Action::add('init', 'my_function');
Action::add('init', function() { /* code */ });
Action::add('save_post', [$this, 'onSavePost']);
Action::add('init', [new MyHandler(), 'handle']);

Constructor injection

When using Namespace\Class@method, constructor dependencies are auto-resolved via illuminate/container:

namespace App\Hooks\Modules;
use App\Services\Metrics; use Illuminate\Http\Request;

class Shop {
    public function __construct(private Request $r, private Metrics $m) {}
    public function init(): void { /* $this->r and $this->m injected */ }
}
Action::add('init', 'App\Hooks\Modules\Shop');

Run / check / remove

Action::run('my_action');
Action::run('my_action', $data);
if (Action::exists('my_action')) { /* registered */ }
$a = Action::add('init', 'MyClass@method');
$a->remove('init');                        // default priority 10
$a = Action::add('init', 'MyClass@method', 5);
$a->remove('init', 'MyClass@method', 5);  // custom priority
