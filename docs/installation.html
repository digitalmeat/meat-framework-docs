Requirements

The server requirements are the same as WordPress with a few additions:

  • PHP >= 8.0 (8.1+ recommended)
  • Composer >= 2.0
  • Intl PHP Extension
  • MySQL 5.7+ or MariaDB 10.3+

Install Composer

MEAT Framework uses Composer to manage its dependencies. Install it globally if you haven't already: 

# macOS / Linux
curl -sS https://getcomposer.org/installer | php
mv composer.phar /usr/local/bin/composer

Install the MEAT Framework

Open your Terminal and create a new project:

composer create-project digitalmeat/meat-framework my-project-name

This creates a my-project-name directory and downloads WordPress, the framework, and all its dependencies automatically.

The public directory

MEAT Framework is not configured like a classic WordPress installation. The web server must point to the htdocs subdirectory, not the project root. 

# nginx example
root /var/www/my-project/htdocs;

# Apache example
DocumentRoot /var/www/my-project/htdocs

Docker (recommended)

The framework ships with a production-grade Docker setup. To get started:

# 1. Create a shared network (first time only)
docker network create -d bridge localnetwork

# 2. Start a MySQL container (first time only)
docker run --name mysqlserver \
 -e MYSQL_ROOT_PASSWORD=root \
 --network localnetwork \
 -p 3306:3306 --restart=always -d mysql:latest

# 3. Build and start project containers
docker-compose build
docker-compose up

# 4. Install PHP dependencies inside the container
docker-compose exec app php -d memory_limit=-1 \
 /usr/local/bin/composer install
Note: For local development without Docker, MEAT Framework supports Laravel Valet with a bundled local driver. Point Valet at the htdocs directory.

Artisan CLI

MEAT Framework uses Laravel Artisan as its CLI tool. To see all available commands: 

php artisan

Common commands you'll use often:

php artisan key:generate # Generate APP_KEY
php artisan salts:generate # Generate WordPress salts
php artisan migrate # Run database migrations
php artisan make:controller # Scaffold a controller
php artisan make:model # Scaffold a model

Install a theme

No default theme is installed on project creation. Install one with: 

php artisan theme:install my-theme

This downloads and installs the theme into htdocs/content/themes/my-theme/ and sets it as the active theme.

Configure WordPress

Instead of editing wp-config.php, all configuration lives in a .env file at project root. Copy the sample and fill in your values: 

cp .env.sample .env

Key variables to set:

APP_URL=https://my-project.test
DATABASE_NAME=my_db
DATABASE_USER=root
DATABASE_PASSWORD=secret
DATABASE_HOST=127.0.0.1

See the Configuration guide for the full reference.
