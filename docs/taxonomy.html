Taxonomy

The Taxonomy facade registers custom WordPress taxonomies.

Basic usage

use Meat\Support\Facades\Taxonomy;

Taxonomy::make('authors', 'books', 'Authors', 'Author')->set();
// Signature: make(slug, post_type|array, plural_label, singular_label)
The taxonomy is only registered once you call set().

Labels

Taxonomy::make('authors', 'books', 'Authors', 'Author')
    ->setLabels([
        'edit_item' => __('Edit Author', 'textdomain'),
        'not_found' => __('No authors found', 'textdomain'),
    ])
    ->set();

Full label list: get_taxonomy_labels()

Customize arguments

Taxonomy::make('authors', 'books', 'Authors', 'Author')
    ->setArguments([
        'public'             => true,
        'hierarchical'       => false,
        'show_in_rest'       => true,
        'show_admin_column'  => true,
        'show_in_nav_menus'  => false,
    ])
    ->set();

Full parameters: register_taxonomy()

Shared taxonomies

// Attach to multiple post types
Taxonomy::make('authors', ['post', 'books'], 'Authors', 'Author')->set();

Term custom fields

use Meat\Support\Facades\{Taxonomy, TaxonomyField, Field};

$author = Taxonomy::make('author', 'post', 'Authors', 'Author')->set();

TaxonomyField::make($author)
    ->add(Field::text('website', ['rules' => 'url']))
    ->add(Field::textarea('bio'))
    ->add(Field::choice('genre', [
        'choices' => ['Fiction', 'Non-Fiction', 'Science', 'History'],
    ]))
    ->set();
