Asset

The Asset facade enqueues CSS and JS files. Call add() then to().

Adding assets

// CSS — front-end
Asset::add('styles', 'css/screen.css', [], '1.0', 'all')->to();
// JS in footer — front-end
Asset::add('scripts', 'js/app.js', ['jquery'], '1.0', true)->to();
// WordPress admin
Asset::add('admin-js', 'js/admin.js', ['backbone'], '1.0', true)->to('admin');
// Login page
Asset::add('login-css', 'css/login.css', [], '1.0', 'all')->to('login');
// Multiple locations
Asset::add('shared', 'js/utils.js', [], '1.0', true)->to(['front','admin']);

External assets

// Extension auto-detected
Asset::add('cdn-jquery', '//cdn.jsdelivr.net/npm/jquery@3/jquery.min.js', [], '3', true)->to();
// No file extension — specify type
Asset::add('gmap', 'https://maps.googleapis.com/maps/api/js?key=KEY', [], '3', true)
    ->setType('script')->to();

Localize data

Uses wp_localize_script():

$asset = Asset::add('app', 'js/app.js', [], '1.0', true)->to();
$asset->localize('meatApp', [
    'ajaxurl' => admin_url('admin-ajax.php'),
    'nonce'   => wp_create_nonce('my-action'),
]);

Inline code

$css = Asset::add('theme', 'css/theme.css', [], '1.0', 'all')->to();
$css->inline('.hero { background: #e84a4a; }');

$js = Asset::add('app', 'js/app.js', [], '1.0', true)->to();
$js->inline('var App = App || {};', 'before'); // before the script tag

Custom HTML attributes

Asset::add('gmap', 'https://maps.googleapis.com/maps/api/js', [], '3', false)
    ->setType('script')
    ->attributes(['defer', 'data-env' => 'prod'])
    ->to();

Config & load order

Register asset paths in config/assets.php. Search order: root config → plugins → theme. First match wins. Use unique handles and subdirectory names to avoid conflicts.

'paths' => [
    web_path('dist') => rtrim(config('app.url'), '/') . '/dist',
],
