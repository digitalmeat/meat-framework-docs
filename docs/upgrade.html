Upgrade guide

This guide covers upgrading MEAT Framework between versions. Follow the steps in order and always back up your database before upgrading.

General upgrade process

  1. Read the full changelog for your target version
  2. Commit or stash all local changes
  3. Update composer.json to the new version constraint
  4. Run composer update
  5. Run php artisan migrate for any database changes
  6. Clear caches: php artisan cache:clear && php artisan route:clear && php artisan view:clear
  7. Run your test suite

npm → pnpm migration

MEAT Framework now uses pnpm exclusively. If you are upgrading from a project that used npm:

  1. Install pnpm: corepack enable pnpm (or brew install pnpm)
  2. Delete node_modules/ and package-lock.json
  3. Run pnpm install
Known difference: pnpm 10 does not run dependencies' install scripts by default. @parcel/watcher prints a "Ignored build scripts" warning — this is harmless. The production build, lint, and format checks all work correctly.

PHP 8.x compatibility

MEAT Framework supports PHP 8.0, 8.1, 8.2, and 8.3. If you are upgrading from PHP 7.x:

  • Replace deprecated each(), create_function(), and ereg_*() calls
  • Named arguments and union types are now available — use them for new code
  • Set APP_DEBUG=false in .env during WordPress installation to suppress PHP 8 compatibility notices from WordPress core itself

Environment variables

New variables added to .env.sample in recent versions:

# Docker / container config
APP_URL_PUBLIC=https://your-public-domain.com

# Queue (if using Horizon)
HORIZON_PREFIX=my-app

# Multi-environment
APP_ENV=production  # local | staging | production
