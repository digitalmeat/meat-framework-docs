Database

MEAT Framework includes illuminate/database providing the Query Builder, Eloquent ORM, Migrations, and Collections.

Configuration

MySQL is the default. Configure in config/database.php. Connection credentials come from .env:

DATABASE_NAME=my_db
DATABASE_USER=root
DATABASE_PASSWORD=secret
DATABASE_HOST=127.0.0.1
DATABASE_PREFIX=wp_

Query Builder

use Illuminate\Support\Facades\DB;

$posts = DB::table('posts')
    ->where('post_status', 'publish')
    ->where('post_type', 'post')
    ->orderBy('post_date', 'desc')
    ->limit(10)
    ->get();

$post = DB::table('posts')->find(42);

Migrations

# Create migration file
php artisan make:migration create_customers_table

# Run all pending migrations
php artisan migrate

# Rollback last batch
php artisan migrate:rollback

# Show status
php artisan migrate:status

Warning: php artisan migrate:fresh drops ALL tables including WordPress tables. Use with extreme caution.

Migration example:

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void {
        Schema::create('customers', function(Blueprint $table) {
            $table->id();
            $table->string('name');
            $table->string('email')->unique();
            $table->timestamps();
        });
    }
    public function down(): void { Schema::dropIfExists('customers'); }
};

For the full API see Laravel Database and Eloquent ORM documentation.
