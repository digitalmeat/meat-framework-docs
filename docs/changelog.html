Changelog

Release history for MEAT Framework. Maintained by Digital MEAT.

3.1.x — Current (active maintenance)

MEAT Framework picks up where the original codebase left off, focusing on stability, PHP 8.x compatibility, and security maintenance.

  • PHP 8.1 / 8.2 / 8.3 compatibility fixes
  • Migrated package manager from npm/yarn to pnpm (pnpm@10 via Corepack)
  • Replaced package-lock.json with pnpm-lock.yaml — lockfile is now committed
  • Vite build pipeline (pnpm build, pnpm watch)
  • Docker Compose setup for local development
  • Security patch: updated vlucas/phpdotenv, illuminate/* dependencies to latest compatible versions
  • Pre-commit hook now uses pnpm exec lint-staged

pnpm command reference

corepack enable pnpm    # install pnpm via Corepack (one-time)
pnpm install            # install dependencies
pnpm build              # production build
pnpm watch              # watch mode
pnpm exec <bin>         # run a local binary (replaces npx)

Original codebase lineage

MEAT Framework is based on the 3.1 release of the original WordPress + Laravel stack. The framework uses the following core packages:

  • illuminate/routing
  • illuminate/database
  • illuminate/view
  • illuminate/container
  • vlucas/phpdotenv
