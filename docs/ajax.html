Ajax

The Ajax facade wraps WordPress AJAX registration.

Basic usage

Ajax::listen(string $action, callable $callback, string|bool $logged = 'both');
// $logged: true=logged-in, false=logged-out, 'both'=all users

Example in a Hookable class:

namespace App\Hooks;
use Meat\Hook\Hookable; use Meat\Support\Facades\Ajax;

class AjaxHandlers extends Hookable {
    public function register(): void {
        Ajax::listen('calculate', function() {
            check_ajax_referer('my-nonce', 'security');
            wp_send_json_success(intval($_POST['n'] ?? 0) * 2);
        }, 'both');
    }
}

JavaScript:

jQuery.ajax({
    url: meatApp.ajaxurl, type: 'POST',
    data: { action: 'calculate', security: meatApp.nonce, n: 5 }
}).done(r => console.log(r.data)); // 10

Global JS objects

Front-end: meatApp object (at minimum ajaxurl). Extend via filter:

use Meat\Support\Facades\Filter;
Filter::add('meat_front_global', function(array $data): array {
    $data['nonce']  = wp_create_nonce('my-nonce');
    $data['userId'] = get_current_user_id();
    return $data;
});

Admin: meatGlobal (name fixed, required by core JS):

Filter::add('meat_admin_global', function(array $data): array {
    $data['postId'] = get_the_ID();
    return $data;
});

WordPress localize

For per-script data, prefer Asset::localize() — it scopes the data to a specific script handle via wp_localize_script().
