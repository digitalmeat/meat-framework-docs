Form

The Form facade builds standalone HTML forms validated via illuminate/validation.

Basic usage

use Meat\Support\Facades\Form;

$form = Form::make('contact')
    ->add('name',    'text',     ['label' => 'Name',    'rules' => 'required'])
    ->add('email',   'email',    ['label' => 'Email',   'rules' => 'required|email'])
    ->add('message', 'textarea', ['label' => 'Message', 'rules' => 'required|min:10'])
    ->set();

Controller validation

use Illuminate\Http\Request;

public function store(Request $request)
{
    $data = $request->validate([
        'name'    => 'required|string|max:100',
        'email'   => 'required|email',
        'message' => 'required|min:10',
    ]);

    wp_mail(get_option('admin_email'), 'New message from '.$data['name'], $data['message']);
    return redirect()->back()->with('success', 'Message sent!');
}

CSRF protection

The web middleware group includes CSRF protection automatically:

<form method="POST" action="{{ route('contact.store') }}">
    @csrf
    <!-- fields -->
    <button type="submit">Send</button>
</form>

Field types

Supported: text, email, url, number, tel, password, textarea, checkbox, radio, select, date, file, hidden. See the Field guide for options.
