Metabox

The Metabox facade registers custom WordPress metaboxes for any post type.

Basic usage

use Meat\Support\Facades\Metabox;

Metabox::make('properties', 'post')->set();
Metabox::make('properties', ['post', 'page'])->set();

Title, context & priority

Metabox::make('properties', 'post')
    ->setTitle(_x('Product details', 'metabox', 'textdomain'))
    ->setContext('side')    // 'normal' (default) | 'side' | 'advanced'
    ->setPriority('high')  // 'default' | 'high' | 'low'
    ->set();

Custom fields

Fields are managed via a REST API and React components. Use Field instances:

use Meat\Support\Facades\Field;

Metabox::make('book_details', 'post')
    ->setPrefix('book_')
    ->add(Field::text('author'))
    ->add(Field::text('isbn'))
    ->add(Field::integer('year'))
    ->set();

Grouped fields (tabs)

use Meat\Support\Section;

Metabox::make('book_details', 'post')
    ->add(new Section('general', 'General', [
        Field::text('author'), Field::text('publisher'),
    ]))
    ->add(new Section('meta', 'Details', [
        Field::text('isbn'), Field::media('cover'),
    ]))
    ->set();

Validation

Uses illuminate/validation:

Metabox::make('settings', 'post')
    ->add(Field::text('author', [
        'rules'    => 'required|min:3',
        'messages' => ['required' => 'Author name is required.'],
    ]))
    ->set();

Retrieve data

// Field stored with prefix "book_"
$author = get_post_meta($post_id, 'book_author', true);

Custom UI callback

Metabox::make('custom', 'post')
    ->setCallback(function($args) {
        return view('admin.metabox.custom', [
            'post'    => $args['post'],
            'metabox' => $args['metabox'],
        ]);
    })->set();

Capability & template restrictions

Metabox::make('advanced', 'post')
    ->setCapability('manage_options')
    ->setTemplate(['featured', 'wide'], 'page')
    ->set();
