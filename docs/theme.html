Theme handbook

A MEAT Framework theme is a standard WordPress theme that leverages the framework's routing, views, and asset pipeline.

Install a theme

php artisan theme:install my-theme

This downloads the theme boilerplate into htdocs/content/themes/my-theme/ and sets it as the active theme.

Theme structure

my-theme/
├── config/
│   ├── assets.php     # asset paths (& dist URL)
│   ├── menus.php      # nav menu registration
│   ├── supports.php   # theme support declarations
│   ├── templates.php  # page template slugs
│   └── theme.php      # views directories
├── dist/              # compiled assets output (never edit)
├── resources/
│   ├── js/            # JavaScript source
│   └── scss/          # SCSS source
├── views/             # Blade/Twig templates
│   ├── layouts/
│   ├── pages/
│   └── partials/
├── functions.php      # theme bootstrap
└── style.css          # WP theme header

functions.php

The theme's functions.php registers assets, menus, and theme supports:

use Meat\Support\Facades\Asset;

// Enqueue compiled assets
Asset::add('theme-css', 'css/theme.css', [], '1.0', 'all')->to('front');
Asset::add('theme-js',  'js/app.js', ['jquery'], '1.0', true)->to('front');

// Register navigation menus
register_nav_menus([
    'primary' => 'Primary Navigation',
    'footer'  => 'Footer Navigation',
]);

// Theme support
add_theme_support('title-tag');
add_theme_support('post-thumbnails');
add_theme_support('html5', ['search-form', 'comment-form', 'gallery']);

Theme routes

Routes can be defined in the root routes/web.php (recommended) or in the theme's routes.php file. Theme routes override root and plugin routes.

Page templates

Register page templates in config/templates.php:

return [
    'template-full-width' => 'Full Width',
    'template-landing'    => 'Landing Page',
    'template-sidebar'    => 'With Sidebar',
];

Use in routes:

Route::any('template', ['template-full-width', function($post, $query) {
    return view('templates.full-width', compact('post'));
}]);

Asset build

pnpm install   # install dependencies
pnpm build     # production build to dist/
pnpm watch     # watch mode for development
