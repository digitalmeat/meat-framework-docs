Plugin handbook

MEAT Framework supports custom plugins that use the same application layer as the root project — routing, hooks, views, and Eloquent.

Create a plugin

A MEAT Framework plugin is a standard WordPress plugin with an application bootstrap. Create the plugin directory in htdocs/content/plugins/my-plugin/:

my-plugin/
├── config/
│   └── my-plugin.php   # plugin-specific config
├── resources/
│   └── views/          # plugin views
├── routes/
│   └── routes.php      # plugin routes (override root routes)
├── app/
│   ├── Hooks/          # hookable classes
│   └── Http/
│       └── Controllers/
├── my-plugin.php       # WP plugin header + bootstrap
└── composer.json

Plugin bootstrap (my-plugin.php)

<?php
/**
 * Plugin Name: My MEAT Plugin
 * Description: A plugin using MEAT Framework
 * Version: 1.0.0
 */

// Register hooks with the application
add_filter('meat_app_hooks', function(array $hooks): array {
    $hooks[] = App\Plugins\MyPlugin\Hooks\RegisterPostTypes::class;
    return $hooks;
});

Plugin routes

Routes defined in the plugin's routes/routes.php take precedence over the root routes/web.php. Plugin routes are overridden by theme routes.

// routes/routes.php
Route::get('my-plugin/api/data', [MyController::class, 'data']);

Plugin assets

Register the plugin's asset directory in its bootstrap:

add_action('meat_app_assets', function($theme): void {
    Asset::add('my-plugin-css', 'css/plugin.css', [], '1.0', 'all')
        ->setLocation(plugin_dir_path(__FILE__) . 'dist', plugin_dir_url(__FILE__) . 'dist')
        ->to('front');
});
