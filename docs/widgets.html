Widgets

The Widget facade registers custom classic WordPress widgets.

Register a widget

use Meat\Support\Facades\{Widget, Field};

Widget::make('newsletter', 'Newsletter Signup')
    ->description('Newsletter signup form widget')
    ->add(Field::text('title',        ['default' => 'Subscribe']))
    ->add(Field::textarea('intro'))
    ->add(Field::text('button_label', ['default' => 'Subscribe now']))
    ->set();

Widget view

Create views/widgets/newsletter.blade.php:

@if($title)
    <h3 class="widget-title">{{ $title }}</h3>
@endif
@if($intro)
    <p>{{ $intro }}</p>
@endif
<form method="post" action="{{ home_url('/newsletter') }}">
    @csrf
    <input type="email" name="email" placeholder="you@example.com" required />
    <button type="submit">{{ $button_label }}</button>
</form>

Register sidebar areas

register_sidebar([
    'name'          => 'Primary Sidebar',
    'id'            => 'primary-sidebar',
    'before_widget' => '<div class="widget %2$s">',
    'after_widget'  => '</div>',
    'before_title'  => '<h3 class="widget-title">',
    'after_title'   => '</h3>',
]);

Display in templates

@if(is_active_sidebar('primary-sidebar'))
    <aside class="sidebar">
        {!! dynamic_sidebar('primary-sidebar') !!}
    </aside>
@endif
WordPress 5.8+ added block-based widgets. MEAT Framework's Widget facade targets the classic widget system which remains available.
